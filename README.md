# Бот для запису клієнтів на стрижку

> 👉 Якщо ти барбер і просто хочеш запустити бота — відкрий **ІНСТРУКЦІЯ.md**.
> Цей файл — технічний опис проєкту.

## Структура проєкту

```
barber_bot/
├── bot.py              — головний файл, запускай саме його
├── config.py           — токен, ID адміна, робочий графік
├── database.py         — вся робота з базою даних (SQLite)
├── keyboards.py        — клавіатури (кнопки)
├── states.py           — стани для покрокових діалогів
├── utils.py            — час у правильному поясі та екранування HTML
├── handlers_client.py  — дії клієнта
├── handlers_admin.py   — дії барбера (адміна)
├── scheduler.py        — нагадування о 9:00 та щомісячна аналітика
└── requirements.txt     — список бібліотек
```

## Крок 1. Отримати токен бота

1. Відкрий Telegram, знайди **@BotFather**
2. Напиши `/newbot`, вкажи ім'я і username бота
3. Скопіюй токен (виглядає як `123456789:ABCdefGHIjklmNOPqrs...`)

## Крок 2. Дізнатись свій Telegram ID

1. Знайди в Telegram бота **@userinfobot**
2. Напиши йому `/start` — він покаже твій ID (число)

## Крок 3. Вписати дані в .env

Скопіюй `.env.example` у `.env` і встав свої значення:

```
BOT_TOKEN=твій_токен_від_BotFather
ADMIN_IDS=твій_telegram_id
```

**Не вписуй токен прямо в `config.py`** — так він рано чи пізно потрапить у git.
Файл `.env` і база `*.db` у git не потрапляють (див. `.gitignore`).

Додаткові (необов'язкові) налаштування — теж через змінні оточення:

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `DB_PATH` | `barber_bot.db` | де лежить база |
| `MAX_ACTIVE_BOOKINGS` | `2` | максимум активних записів на одного клієнта |
| `BROADCAST_DELAY` | `0.05` | пауза між повідомленнями розсилки, секунди |
| `CANCEL_DEADLINE_HOURS` | `3` | за скільки годин клієнт ще може скасувати сам |

## Крок 4. Встановити залежності

```bash
pip install -r requirements.txt
```

## Крок 5. Запустити локально (для тестування)

```bash
python bot.py
```

Якщо все правильно — побачиш повідомлення "Бот запущено". Напиши своєму боту `/start` у Telegram — маєш побачити адмін-меню (бо твій ID у ADMIN_IDS).

Щоб перевірити клієнтську частину — попроси друга написати боту, або зайди в Telegram з іншого акаунта.

**Важливо:** поки термінал з `python bot.py` запущений — бот працює. Закриєш термінал — бот зупиниться.

## Як зробити, щоб бот працював постійно (24/7)

Локальний запуск підходить тільки для тестів. Щоб нагадування о 9:00 і щомісячна аналітика реально спрацьовували, потрібен сервер, який ніколи не вимикається.

### Варіант 1: Railway (найпростіше для початку)

1. Зареєструйся на [railway.app](https://railway.app)
2. Заведи акаунт на [github.com](https://github.com), завантаж туди папку з ботом (як репозиторій)
3. У Railway: New Project → Deploy from GitHub repo → обери свій репозиторій
4. У розділі Variables додай:
   - `BOT_TOKEN` = твій токен
   - `ADMIN_IDS` = твій Telegram ID
   - `DB_PATH` = шлях на під'єднаному Volume, наприклад `/data/barber_bot.db`
     (без цього база зітреться при кожному передеплої)
5. Railway сам встановить залежності та запустить `bot.py`

Орієнтовна вартість: ~5$/міс.

### Варіант 2: VPS (Hetzner, Timeweb) — дешевше, але треба трохи більше налаштувати

1. Купуєш VPS з Ubuntu (найдешевший тариф — вистачить)
2. Підключаєшся по SSH
3. Встановлюєш Python, копіюєш файли бота
4. Запускаєш через `systemd`, щоб бот сам стартував після перезавантаження сервера і працював у фоні

Якщо оберешь цей варіант — напиши, і я дам покрокову інструкцію під конкретний сервер.

## Як користуватись ботом (для барбера)

- **📋 Всі записи** — список усіх майбутніх записів, можна скасувати конкретний
- **📊 Статистика** — стрижки й заробіток за поточний і минулий місяць, записи на тиждень
- **➕ Записати клієнта** — записати вручну (можна навіть на час поза графіком)
- **💰 Встановити ціну** — змінити ціну; після цього бот окремо спитає, чи розсилати клієнтам
- **🚫 Закрити день** — прибрати всі вільні вікна на обраний день (наявні записи залишаться)
- **🔓 Відкрити день** — повернути назад закритий день або окремі закриті слоти
- **🔒 Закрити слот** — закрити одне конкретне вікно
- **📢 Розсилка** — довільне повідомлення всім клієнтам, із попереднім переглядом і підтвердженням

Будь-який покроковий діалог обривається командою `/cancel`.

Клієнти бачать спрощене меню: **📅 Записатись**, **🗒 Мої записи**, **💈 Ціна та графік**.
Записатись можна максимум на `MAX_ACTIVE_BOOKINGS` вікон одночасно; скасувати самому —
не пізніше ніж за `CANCEL_DEADLINE_HOURS` годин до стрижки.

Щодня о 9:00 клієнтам ідуть нагадування, о 9:05 барберу — план на день,
1-го числа о 9:10 — аналітика за минулий місяць.

## Примітка щодо графіка роботи

Графік заданий у `config.py` у змінній `WORK_SCHEDULE`. Якщо захочеш змінити години роботи — онови там, наприклад:
```python
WORK_SCHEDULE = {
    0: ("17:00", "21:20"),  # Понеділок
    ...
}
```
Числа 0–6 відповідають дням тижня (0 = понеділок, 6 = неділя).
